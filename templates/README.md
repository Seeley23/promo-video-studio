# Szablony (w budowie)

Uniwersalne sceny sterowane profilem marki (`brands/<marka>/brand.json`) i scenariuszem. Pierwsza wersja powstanie z filmu `examples/boostnow-hyperframes/` – każda scena stanie się szablonem z parametrami zamiast tekstów i kolorów BoostNow.

| Scena | Rola w filmie | Parametry |
|---|---|---|
| hook-overload | hak: przeładowana reklama + licznik czasu | tytuł, czas, hasła „starego sposobu” |
| problem-trio | trzy błędy/problemy, każdy z własną animacją | nagłówek, 3 × tytuł |
| ui-pushin | ekran produktu (odtworzony z kodu) + zbliżenie kamery na jeden element | komponent UI, cel zbliżenia, tytuł po zbliżeniu |
| carry-to-logo | element z poprzedniej sceny zwija się w logo | logo, linia pod logo |
| verb-slot | 2–4 czasowniki/korzyści jak w automacie | lista czasowników, ikony |
| results-countup | wyniki z licznikami + zbliżenie na główną liczbę | etykiety, wartości, nagłówek sekcji |
| endcard | logo + CTA + adres | logo, CTA, URL |

Silnik szablonów (HyperFrames czy Remotion) wybierzemy po porównaniu z filmami ze skilli launch-video i video-shotcraft na tej samej marce.
